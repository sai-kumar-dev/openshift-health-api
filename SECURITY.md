# Security Policy

Version 0.3.x receives security fixes while it is the current release line.
This portfolio project makes no response-time guarantee.

Report sensitive findings privately to the repository owner using a private
channel listed on their GitHub profile. Do not open a public issue containing
credentials, tokens, internal hosts, exploit details, logs with personal data,
or cluster information. Include the affected version, reproduction, impact, and
a proposed mitigation when possible.

In scope are the Python API, container definition, dependency supply chain, and
deployment manifests. Third-party infrastructure and intentionally public,
non-sensitive endpoint metadata are outside project scope. See
`docs/security.md` for controls, assumptions, and known limitations.
